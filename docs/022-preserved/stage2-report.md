# 第二阶段第一个功能块项目报告

仓库：https://github.com/xuxAkiss/database-lab1

本轮在第一阶段 HEAD e0b3391ba12b139f5379ac13c9736a2df78cd07e 上增量实现独立题目、版本历史、题库、指定账号共享、原问卷选题/换版和使用查询。未推送远端。教师变更第一至七节为本轮范围，第八节跨问卷统计延期。版本分支、恢复生成新版本、只读共享和撤销保留快照是采用的用户推荐规则，不冒称教师指定实现。

## 第一阶段的设计是什么
FastAPI/PyMongo、原生前端；users/sessions 提供身份与会话，surveys 管理所有权、固定链接和发布指针，survey_edits 保存 CAS 编辑稿，survey_versions 保存不可变快照。题目嵌入问卷；fill_drafts/participations/submissions 区分草稿、参与和历史提交。原统计按问卷发布版取每账号最新提交，维持匿名边界。

## 新需求带来了哪些问题
嵌入题缺少跨卷身份，复制相同文字不能证明同源；本卷跳转 ID 不能复制到别卷；共享实时读取最新题会改变旧问卷；撤销共享不能破坏已授权快照。使用查询可能暴露其他账号私有问卷，客户端分配版本号会有并发冲突。

## 为什么需要修改原设计
增加独立稳定题身份与不可变版本，用引用记录出处，用问卷快照保证历史稳定。不要求旧题强制转换，不通过标题自动合并，不另建问卷系统。

## 修改了哪些部分
新增 backend/questions.py、frontend/library.html/library.js、schema 安装脚本和专项测试。原 main.py 注册路由；survey_models.py 增加可选 source；surveys.py 在原创建和保存事务中核验来源；surveys.html/js 增加题库筛选、固定版本导入/换版、旧题导出。原 auth.py、filling.py、filling_engine.py、statistics.py 未修改。

## 数据结构如何变化
新增 questions（身份/作者/共享/服务端序号）、question_versions（不可变定义/父版本/恢复来源/派生来源/可选旧题来源）、question_banks（个人分类及 revision）。原题实例可带 source:{question_id,version_id}，保留本卷 id、规则与内容。其余核心集合沿用，无批量迁移。schema、索引和具体字段见 stage2-system.md 与 stage2-mongodb-schema.json。

MongoDB 文档适合题型各异的校验字段；版本独立集合避免单文档历史无限增长，题库引用身份避免重复历史。问卷快照冗余用于保证发布、填写、历史校验不依赖实时题库权限或内容。所有业务数据仍在 MongoDB，无关系库或现成问卷框架。

## 程序如何调整
事务原子分配题版本序号并插入内容，任意旧版本可作父节点；恢复复制内容生成新版本，不删除后续历史。共享接收者只能读取/使用，修改需派生自己拥有的新题。问卷保存精确比较来源版本定义，并写 access_fence 与并发撤销串行化；已有相同实例/来源/内容的快照仍可保存和发布。

导入清空外卷规则并生成新实例 ID；换版保留本卷 ID/rules，原 validate_structure 校验选项、目标、自跳、循环和条件冲突。失效返回 422，不静默修改规则。发布仍复制原编辑稿并切换原固定链接，历史答卷不改。

使用查询只对自己的问卷返回详情，他人仅返回 edit/current/historical 引用次数，不含标题、问卷 ID、账号、链接或填写数据。次数不是人数，也不是去重问卷数。题目共享不授予他人答卷统计权。

## 是否遇到兼容性问题
旧题没有 source，正常读取；模型规范化省略空 source，避免改变旧结构。旧代码 extra=forbid 无法解释新字段，不能直接降级覆盖新数据。恢复策略应停写备份，在副本验证兼容补丁并保留新历史，禁止删库重建；未进行灾难恢复演练。

显式旧题导出在事务中记录 survey_id/edit_revision/instance_id，关联当前编辑稿，并支持重复请求复用。历史发布不改，只能证明显式导出时的来源，不能伪造更早同文字历史的家族关系。legacy_origin 只对作者返回。

首次本机 MongoDB 访问被沙箱阻止，获准执行后发现服务未运行，使用原脚本启动原数据目录。Git diff 发现 Windows CRLF 被仓库规则当作尾部空白，最终保留旧文件原换行格式以减少无关差异，检查时将 CRLF 作为合法行尾。浏览器有一次页面刷新后输入焦点失效，重新观察后成功；最终大型工具调用未返回且被中断，其未执行的文档写入重新完成，未将中断算作通过。

## 跨问卷统计仍需确定
1. 具体题版本、question_id 家族及 derived_from 派生新身份之间的统计关系。
2. 题意、题型、选项、单位、校验变化后的可比性与显式映射；不兼容版本默认分开。
3. 同账号跨问卷、跨发布版本、多次提交是否及如何重复计数。
4. 当前/历史发布、关闭/截止卷与时间范围的取值；草稿不算答卷。
5. 题作者、共享接收者、问卷作者的统计权限，以及匿名和撤销后的授权。

上述口径未定前不实现合并统计；同名题、未知来源历史与不兼容版本不自动合并。
