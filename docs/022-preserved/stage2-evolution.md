## 原设计与扩展对应
|原模块/集合|新需求暴露的问题及修改理由|扩展方案|
|---|---|---|
|auth/users/sessions|题目共享需要账号授权|复用登录、CSRF、注册账号 ID，不另建身份系统|
|surveys/survey_edits|嵌入题目缺少跨卷身份|原实例增加可选 source；旧题无 source 继续使用；显式保存旧题才建立身份|
|survey_versions|题库更新不能改历史|继续不可变发布快照，新发布包含固定题目版本来源|
|survey_models|题目内容和本卷跳转混合|独立定义去除实例 ID/rules/source；导入保留实例 ID 和本卷规则并全量校验|
|fill_drafts/participations/submissions|历史答卷依赖原问卷版本|不迁移、不改写；填写状态机原样沿用|
|statistics|跨卷口径尚未定义|原单卷统计保留，不实施跨卷合并|
|新增 questions/question_versions|需要稳定身份、分支、恢复、共享|MongoDB 引用固定版本、不可变内容、事务分配版本号|
|新增 question_banks|题库只是归类|题库成员引用稳定题 ID，移除不删题或历史|

## 规则来源
教师原要求为变更文档第一至七节，本轮第八节延期。稳定身份、恢复生成新版本、指定账号只读共享、撤销保留已授权快照、使用隐私计数属于用户推荐默认规则，本实现采用，不冒称教师指定算法。无需强制迁移旧题；同名题不合并。

## 兼容性与恢复
