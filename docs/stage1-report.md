# 第一阶段项目完成报告

日期：2026-10-21。范围：MongoDB问卷系统第一阶段；统计补齐后完成本轮验收与文档。未实现第二阶段未知要求。本文提供可复核证据，不以“所有测试通过”代表无限边界或生产就绪。

## 目标与系统设计

支持注册用户创建、配置、发布并分享问卷，所有填写者登录，草稿保存与恢复、可配置跳转、历史提交及创建者统计。FastAPI同步PyMongo与原生页面便于解释和运行；数据库为既有本地单节点复制集。没有重写认证、迁移数据或引入现成问卷系统框架。

系统及操作：[system.md](system.md)；数据与schema/索引：[database.md](database.md)；API：[api.md](api.md)；跳转与校验：[logic.md](logic.md)。教师要求、用户选择、默认值分别标明，逐条覆盖见 [requirements-matrix.md](requirements-matrix.md)。评分依据为MongoDB35/后端25/测试10/文档15/AI15，不预测得分。

## 数据设计理由与兼容

固定surveys身份和链接，survey_edits保存可变修订，survey_versions内嵌完整不可变题/选项/规则；历史答卷与草稿独立引用版本，避免单文档无限膨胀。结构内嵌适合整卷读取及联合规则检查；用户、会话、参与与历史按生命周期分离，而非机械按每个选项拆关系表。

保存编辑不改已发布；成功重新发布才切当前指针；保留旧版本/旧提交，旧草稿只读，新版本资格和统计独立。发布/关闭/提交共享协调写；CAS阻止并发覆盖，事务协调历史/最新引用/草稿消费，幂等保证请求重放。序号在账号+版本内递增，不依赖提交时间唯一。

## 跳转、校验与统计

完全匹配多选产生升序去重目标，连续跳转优先，普通队列补完可选题及必答题；禁止循环，已访目标不自动排队。来源图支持改答撤销未执行链，同时保留独立来源、答案、已访状态。结束仍检查全卷必答。后端执行形状、选项、数量、文字、数字等校验，草稿可不完整但不能伪造状态。

统计在同一snapshot事务内固定版本，历史匹配版本后按账号分组取最高sequence整份答卷，再按题汇总；不能先筛非空再选最新。成功次数和参与人数分开，草稿/旧版不计。数字0有效，空值不当0，零有效均值null。响应无系统身份或答卷关联字段，文本自述照实保留；无跨题行对应关系。
