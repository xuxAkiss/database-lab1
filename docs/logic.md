# 跳转、校验与统计关键逻辑

详尽实现说明及已发生修订见 [filling.md](filling.md)、[surveys.md](surveys.md)、[database.md](database.md)。此页汇总现行语义。

配置：单选匹配选项；多选比较完整集合（顺序无关，子集/超集不匹配）；数字支持 eq/lt/lte/gt/gte。目标按版本题序升序去重，拒绝不存在引用、自环和有向环。保守默认拒绝重叠数字区间（按实数域）、重复条件、结束同时带目标，不猜测冲突优先级。

运行：普通顺序包含所有未访题（含可选）；新连续跳转优先，已访目标不自动入队。
- 1→5：1,5,2,3,4,6。
- 第1题完全匹配{A,B}生成[3,5]；第3题命中生成[7]：1,3,7,5,2,4,6。
- 目标列表[5,3,5]配置规范化为[3,5]；多来源目标仅排一次。

服务端保存答案、当前题、已访、待答、有效来源图和上下文。返回改答删旧来源和失去全部支持的后代，独立来源保留，已答内容与已访保留，再按新答案重算。队列虽可重算仍原子保存在草稿内供恢复。无通用事件平台，不保存每次按键历史。

有规则时只能返回已访，结束时必答缺失例外允许点提示补答；无规则可自由导航。结束动作不免除全卷最终校验。前端提示便于使用，后端决定是否允许前进/提交；不接受客户端上传队列或已验证标记。

校验：单选合法ID，多选禁止重复/伪造并检查数量；文本去明确 Unicode White_Space 后数码点；数字合法十进制/科学计数法、有限值、上下界与整数。非必答空白跳过最小限制，不把空数字当0。未完整但形状合法的输入可存草稿；前进和提交才执行相应完整性校验。

历史修订：早期“覆盖旧答卷”已被用户撤销，现为每次成功提交追加独立历史；多选“禁止同时命中”已被完全匹配规则产生升序目标列表替代。不能把这些修订说成最初方案或教师确认的具体实现。现行统计在版本内取账号最新整份答卷，空白不回填。
